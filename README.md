# 👋 chrizantoz

🛠️ Free, open-source tools for people who run their own stuff: home servers, media libraries, consoles and homebrew.

- 🩺 [Auditarr](https://github.com/chrizantoz/auditarr) — nightly quality control for a Sonarr / Radarr / Bazarr / Plex library. Finds broken downloads, wrong languages and missing subtitles while you sleep, then fixes them.
- 💾 [Dedupearr](https://github.com/chrizantoz/dedupearr) — the truth about your storage: tells you, per video file, whether it is the real copy, a hardlink, a second copy, a leftover or an orphan, with the evidence, and what your seeding rule lets you remove. Companion to Auditarr.
- 🧪 [arr-mock](https://github.com/chrizantoz/arr-mock) — a fake Sonarr, Radarr and Bazarr in one file, with a chaos mode, for testing arr companion apps.

🗺️ What is coming next for all of them: the [Apps roadmap board](https://github.com/users/chrizantoz/projects/1). Unraid users find the templates in [unraid-templates](https://github.com/chrizantoz/unraid-templates).
